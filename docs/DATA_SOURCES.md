# Data sources & provenance

**Nothing in the seeded dataset is an official source or statistic.** I had no network access to official repositories while building, so all seed content is authored/synthetic and labelled `DEMO` throughout the UI, API (`is_demo`) and exports.

| Asset | Location | Nature | Label in UI |
|---|---|---|---|
| 14 documents | `data/seed/documents/*.md` | Authored illustrative text; organizations are explicitly "(fictional)"; one is `restricted` to demonstrate access control | `DEMO DOCUMENT` / `DEMO SOURCE` |
| District indicators 2019–2024 (6) | generated by `app/seed/gis.py` (seed 26019) | Synthetic pseudo-random with trends; no relationship to real statistics. Karnataka 2024 mean digitization is calibrated to 62% to match the demo story | `DEMO / SYNTHETIC DATA` |
| Boundaries | generated | Hex tiles at *approximate* district-HQ coordinates; **not survey or official boundaries**, adjacency not implied | "Schematic tiles" note on every map |
| Model coefficients | `data/seed/models/*.json` | Synthetic demo calibration, each with a provenance string | `DEMO CALIBRATION` |
| Demo users | `app/seed/identity.py` | Password `Demo@12345` — **local demos only** | — |

## Using real data
1. **Documents** — put PDFs in `data/documents/` (+ optional `metadata.csv`), run `python -m scripts.ingest --no-approve`, approve in Admin. Set `is_demo=false`, real `organization`, `publication_date`, `source_url`, `authority_level`.
2. **Indicators** — replace `seed_gis` with an importer writing `Observation` rows linked to a `DataSource(is_demo=false, url, license)`; the DEMO labels disappear automatically.
3. **Boundaries** — load official GeoJSON into `regions.geometry` (`is_schematic=false`). On PostgreSQL the migration also maintains a PostGIS `geom` column.

Suggested public places to look (verify licence/terms yourself): the Department of Land Resources (DILRMP) portal, state revenue/land-record portals, data.gov.in, NITI Aayog and World Bank publications. These are pointers, not content that ships with this repo.
